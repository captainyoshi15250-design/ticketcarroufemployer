Comment utiliser votre propre Firebase sur GitHub Pages ?
  1. Créez un projet gratuit sur console.firebase.google.com.
  2. Activez Authentication → Sign-in method → Anonyme.
  3. Activez Firestore Database (en mode production ou test avec lecture/écriture autorisée).
  4. Collez l'objet firebaseConfig de votre projet ci-dessous puis cliquez sur « Télécharger index.html pré-configuré » pour le déposer sur GitHub Pages.
